# Buhkari_Criticism_Website

Rahle — Buhârî şerh literatüründe tenkit araştırma sisteminin şifreli yayın kopyası.

**Adres:** https://ramazan9838.github.io/Buhkari_Criticism_Website/

İçerik henüz yüklenmedi. Bu depo yalnız giriş sayfasını (`index.html`) ve şifreli dosyaları (`kasa.json`, `veri/`) taşıyacak; içerik AES-256-GCM ile şifrelidir ve yalnız şifreyle tarayıcıda açılır. Kaynak kod ve çalışma verileri ayrı, özel bir depodadır (Rahle). Dosyaları elle düzenlemeyin; yeni sürüm özel depodaki `araclar/yayin/yayinla.py` ile üretilir.
